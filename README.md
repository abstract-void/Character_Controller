# Character Controller

This is a modular character controller. It's still a work in progress, but as of now it can move, jump (with support for double-jumping and more), slide and detect stairs.

The modularity is already there too, and I'm thinking of ways to further improve it. I want this to be as versatile as possible.

<br>

This controller is for personal use, but in case you want to give it a try, please know that there is a couple of dependencies (including a state machine). So here they are:
- [Finite State Machine](https://github.com/ProjectDew/Finite_State_Machine)
- [Unity utilities](https://github.com/ProjectDew/Unity_Utilities)
